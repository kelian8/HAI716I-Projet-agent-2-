# HAI716I-Projet-agent-2-

Pour lancer un tournoi, taper : "python3" (linux) ou "python" (windows) suivi d'un des tournois suivant : 

"tournois/tournoi_base.py" : tournoi de base avec les 5 strategies du cours 

"tournois/tournoi_2eme_modification.py" : tournoi avec les 6 strategies et la deuxieme modification implémentée

"tournois/tournoi_sans_RANDOM.py" : tournoi sans la strategie RANDOM

"tournois/tournoi_new_strat.py" : tournoi avec les 2 nouvelles strategies ajoutees

"tournois/tournoi_2eme_modification.py" : tournoi avec les 6 strategies et la deuxieme modification implémentée

Pour lancer le tournoi en appliquant la 1 ere modification il faut decommenter les ligne 27 à 32 dans "moteur.py"  et lancer "tournoi_new_strat.py"
